# PDF Infinity Privacy Policy Website

Static, responsive privacy-policy website for the PDF Infinity Android app.

## Files
- `index.html` — policy page and page structure
- `style.css` — responsive styling
- `assets/pdf-infinity-logo.png` — supplied app logo

## Deploy with Vercel
1. Push all files and the `assets` folder to the GitHub repository root.
2. Import the repository into Vercel.
3. Framework Preset: **Other**
4. Root Directory: `./`
5. Build Command: leave blank
6. Output Directory: `.`
7. Install Command: leave blank
8. Deploy.

## Before publishing
Review every statement against the actual production app, permissions, network requests, SDKs, analytics, advertising configuration, and server-side retention. Update the policy and Google Play Data safety form together. Do not claim that files are processed only on-device unless verified.
